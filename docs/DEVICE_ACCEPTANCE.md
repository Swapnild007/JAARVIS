# Physical-device acceptance · Release 1

Target phone: user's OPPO Android device. These checks remain pending until performed on hardware. They cannot be inferred from compilation or an emulator.

Before installation, preserve any notes needed from the older review APK. Its debug signing certificate differs from this build and the original private key was not recovered. Android may require uninstalling it; uninstall clears local app data. Debug keys generated by CI can also differ. This review build is not a production-signed release.

| Check | Expected behavior |
| --- | --- |
| First launch | Eight modules and reactor appear; no microphone permission request until VOICE/reactor activation |
| Keyboard commands | `time`, `date`, `battery` return device data with local time zone |
| Permission denial | Deny microphone, then submit `battery`; keyboard still works, no continuous recording |
| Voice recognition | Grant microphone; speak `what time is it`; verify recognition, response and audio on this phone |
| Offline voice | Disconnect network; test only if an on-device recognizer/language is installed; otherwise observe honest failure and type |
| TTS interruption | Start a spoken response and tap STOP or activate another voice command; old callbacks must not replace the current operation |
| Speech timeout | A stalled recognition session ends within 20 seconds and allows retry |
| Apps | Try Camera, Maps, Clock, Calculator and YouTube; installed app opens or an unavailable message appears |
| Clock review | `alarm 07:30` and `timer 5 minutes` open Clock review; save/start manually and verify actual delivery in Clock |
| Maps safety | `navigate to Pune` opens a location query; route selection remains with the user |
| Background | Home/lock screen stops microphone and audio; returning allows a new command |
| Persistence | Enter note, run command, force-stop and reopen; note/history remain; Clear removes them |
| Navigation | Open all modules and return; edit note with keyboard open and use visible BACK |
| Accessibility | TalkBack labels, font scale 1.5–2.0, small/large screen, cutout, landscape and gesture navigation |
| Motion | Reduced motion and system animations-off disable orbiting; app background does not continue rendering |
| Performance | Inspect actual frame timing, heat and battery use during 10-minute foreground/background sessions |

STOP cancels JAARVIS audio and pending local work. A request already dispatched to Clock/Maps/another app must be cancelled in that app. No JAARVIS-owned alarm delivery, wake word, background voice or call-like reminder is implemented.
